5) TShark / Wireshark
   NOT INCLUDED IN THIS PACKAGE.

   This is a "Mode B" build. tools\tshark\ contains a README only — no
   tshark.exe, no Wireshark DLLs, no plugins.

   DBCAP invokes a TShark executable supplied by the user:

     - <DBCAP_HOME>\tools\tshark\tshark.exe   (if the user places one there)
     - the DBCAP_TSHARK environment variable
     - PATH
     - the standard Wireshark install directories

   DBCAP calls TShark as a separate process and reads its text output. It does
   not link to, embed, or redistribute Wireshark code. Because no Wireshark
   binary is distributed in this package, the GPL corresponding-source and
   notice obligations for Wireshark do not attach to this package.

   Wireshark is licensed GPL-2.0-or-later. Users who install it obtain it
   directly from the Wireshark project:
     https://www.wireshark.org/download.html
   Wireshark's own license, copyright holders, and warranty disclaimer are in
   the README.txt and COPYING.txt of that installation.

   This package does not bundle dumpcap, the Wireshark GUI, or Npcap. Live
   capture is out of scope for DBCAP.


6) What DBCAP needs from TShark
   Offline reading of existing .pcap / .pcapng files only.
   Live capture is out of scope.
